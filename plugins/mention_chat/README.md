# 艾特机器人对话

从微信成员列表真正艾特机器人，再附上问题，即可触发回复。只键入看起来像 `@昵称` 的普通文字不会触发；艾特别人也不会触发。

读取范围为本群最近一段时间里各位群友和机器人自己的文字，默认 6 小时、最多 300 条，可在群设置里按群修改。送给模型的只有其中最新的 24 条、合计不超过 2400 字，另加近两天的群日记和当前说话人的少量档案。模型直接输出纯文本，需要实时信息、看图、其他群友档案、更早的日记或聊天时自己调用工具。斜杠指令和接龙指令不带入。回复采用本群当前人格，文字回复会引用对方那条消息。微信无法引用时，才改为真正艾特原发言者。

显示名字优先使用该成员的本群绑定，未绑定时使用缓存中取得的微信名。功能需要成员记录、有效的模型配置和启用的 `mention_chat` 插件。

点名时，若对方引用了这次运行里已经下载的图片，或本人三分钟内刚发过一张，模型可以调用看图工具查看这一张。引用对不上本地文件时不改用别的图。看图由模型配置里的看图模型完成。

群设置里打开「未点名回应」后，机器人说完话 3 分钟内有人发言，或者到了看群间隔，会先问决策模型现在该不该说话，该说就直接发到群里，不引用、不艾特。

清空、跨天、账号切换或人格变化会取消尚未发出的旧回复。

同时启用 `voice_reply`、填写自己的 Fish Audio 配置并在群里选择音色后，回复会合成为微信语音条；成功时只发语音，合成失败时回退文字。配置和指令见[语音回复插件](../voice_reply/README.md)。
